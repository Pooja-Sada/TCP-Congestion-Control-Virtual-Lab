TCP CONGESTION CONTROL VIRTUAL LAB
===================================

FILES
- index.html: website structure and page content
- css/style.css: layout, colours and responsive styling
- js/app.js: TCP Reno-style simulation, chart controls and quiz

HOW TO RUN
1. Extract TCP_Virtual_Lab.zip.
2. Open the extracted TCP_Virtual_Lab folder in Visual Studio Code.
3. Install the "Live Server" extension if it is not already installed.
4. Right-click index.html and choose "Open with Live Server".
5. The site should open in your browser.

IMPORTANT
- Internet is needed for the Chart.js and Google Fonts CDN links in this starter version.
- The simulation is an educational, simplified TCP Reno-style model, not a packet-level network emulator.
- Start the simulation, then use "Introduce packet loss" while it is running.
- Use Reset experiment to apply new initial cwnd and ssthresh slider values.
